# ⚾ 야구 예매 & 커뮤니티 플랫폼 "야모해"

## 🧾 프로젝트 개요

**"야모해"**는 야구 팬을 위한 **예매 + 커뮤니티 통합 플랫폼**입니다.  
전국 각지 야구 구장의 좌석 예매 기능과 함께, 팬들이 자유롭게 소통할 수 있는 커뮤니티 게시판을 제공하여 사용자 편의성과 참여도를 높이는 것이 목표입니다.

---

## 🎯 기획 의도

- 전국 야구장 예매 기능을 하나의 플랫폼으로 통합 → **사용자 편의성 향상**
- 팀/선수/경기/티켓 등에 대해 자유롭게 이야기할 수 있는 **커뮤니티 기능 제공**
- 실제 상용 플랫폼 수준의 웹 애플리케이션 구현을 통한 **개발 경험 축적**

## 🔑 주요 기능

| 기능 구분     | 주요 기능 설명 |
|---------------|----------------|
| **회원 기능** | 회원가입, 로그인, 마이페이지 등 |
| **예매 기능** | 경기 일정 확인, 좌석 선택, 예매, 결제 연동 |
| **좌석 관리** | 좌석 임시 보류(10분), 중복 예매 방지, 결제 시 확정 |
| **커뮤니티**  | 자유 게시판, 팀/선수 별 토론 게시판, 댓글 |
| **관리자**    | 게시글 관리, 경기 정보 등록, 예매 내역 확인 등 |
| **보안 진단** | Nessus 기반 취약점 진단 및 조치 |
